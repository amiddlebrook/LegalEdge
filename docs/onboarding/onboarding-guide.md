## Phase 1: Platform Setup (15 minutes)

### 1.1 Account Creation & Login
1. **Create Account**
   - Go to [legaledge.com](https://legaledge.com)
   - Click "Get Started" or "Sign Up"
   - Choose your plan (start with Free)
   - Enter email and create password
   - Verify your email address

2. **First Login**
   - Return to legaledge.com/login
   - Enter your credentials
   - Complete two-factor authentication (if enabled)

### 1.2 Initial Setup Wizard
The setup wizard will guide you through the basics:

**Portfolio Setup**
```
📊 Add Your First Portfolio

Portfolio Name: [Enter descriptive name]
Description: [Brief description of your strategy]
Holdings: [Add your current positions]

Example:
Name: Tech Growth Portfolio
Description: Technology companies with strong growth potential
Holdings: AAPL (50 shares), MSFT (25 shares), GOOGL (10 shares)
```

**Alert Configuration**
```
🔔 Set Up Your First Alerts

Topics of Interest: [Select relevant topics]
Notification Preferences: [Email, In-app, SMS]
Alert Frequency: [Real-time, Daily digest, Weekly summary]

Example:
Topics: Artificial Intelligence, Healthcare, Finance
Notifications: Email + In-app
Frequency: Daily digest
```

**Platform Tour**
- Quick overview of key features
- Dashboard walkthrough
- Navigation tips

## Phase 2: Portfolio Management (20 minutes)

### 2.1 Adding Your Investments

#### Manual Entry
1. **Navigate to Portfolios**
   - Click "Portfolios" in main navigation
   - Click "New Portfolio" or "+" button

2. **Basic Information**
   ```
   Name: [Descriptive name, e.g., "Retirement Portfolio"]
   Description: [Strategy or purpose, e.g., "Long-term growth"]
   ```

3. **Add Holdings**
   - **Ticker Symbol**: Enter stock symbols (AAPL, MSFT, etc.)
   - **Shares**: Number of shares owned
   - **Purchase Price**: Cost per share (optional but recommended)
   - **Purchase Date**: When you bought the shares (optional)

#### CSV Import (Recommended)
1. **Prepare Your Data**
   Create a CSV file with columns:
   ```
   Ticker,Shares,Purchase Price,Purchase Date
   AAPL,100,150.25,2024-01-15
   MSFT,50,300.00,2024-01-10
   GOOGL,25,2800.00,2024-01-05
   ```

2. **Import Process**
   - Go to Portfolios → Import
   - Upload your CSV file
   - Review the preview
   - Confirm import

#### Integration Setup (Advanced)
For Pro/Enterprise users:
- **Broker Integration**: Link to your brokerage accounts
- **API Integration**: Connect via our REST API
- **File Upload**: Regular CSV uploads

### 2.2 Portfolio Analysis

#### Understanding Your Analysis
Once your portfolio is set up, you'll see:

**Risk Assessment**
- Overall risk score (1-10)
- Risk factors identified
- Diversification analysis
- Concentration warnings

**Legislative Conflicts**
- Bills affecting your holdings
- Risk level assessment
- Recommended actions
- Impact timeline

**Performance Metrics**
- Portfolio value
- Daily/weekly/monthly returns
- Sector allocation
- Top performers/laggards

### 2.3 Portfolio Optimization

#### Rebalancing Recommendations
- **Underweight/Overweight**: Positions outside target allocation
- **Risk Adjustment**: Suggestions to reduce overall risk
- **Tax Optimization**: Tax-efficient rebalancing suggestions

#### Scenario Analysis
- **Best Case**: Optimistic legislative outcomes
- **Worst Case**: Negative regulatory developments
- **Most Likely**: Balanced probability scenarios

## Phase 3: Alert Configuration (15 minutes)

### 3.1 Understanding Alert Types

#### Legislation Alerts
- **New Bills**: Track new legislation in your areas
- **Status Changes**: Monitor progress of existing bills
- **Amendments**: Get notified of significant changes
- **Votes**: Track important congressional votes

#### Market Alerts
- **Earnings Impact**: How legislation affects company earnings
- **Sector Rotation**: Opportunities from regulatory changes
- **Competitive Landscape**: Changes in industry dynamics

#### Portfolio Alerts
- **Conflict Warnings**: New threats to your holdings
- **Opportunity Signals**: Potential investment opportunities
- **Risk Thresholds**: When risk levels exceed limits

### 3.2 Creating Your First Alerts

#### Basic Alert Setup
1. **Go to Alerts Section**
   - Click "Alerts" in main navigation
   - Click "New Alert Configuration"

2. **Define Alert Criteria**
   ```
   Alert Name: AI Regulation Tracking
   Description: Monitor AI-related legislation
   Keywords: artificial intelligence, machine learning, AI regulation
   Jurisdictions: Federal, California
   Severity Threshold: Medium
   ```

3. **Set Notification Preferences**
   - **Email**: Receive notifications via email
   - **In-App**: Show in platform dashboard
   - **SMS**: Text notifications (Pro/Enterprise)
   - **Webhook**: API callbacks for automation

#### Advanced Alert Configuration
- **Smart Filters**: AI-powered relevance scoring
- **Quiet Hours**: Suppress notifications during off-hours
- **Escalation Rules**: Increase urgency for critical developments
- **Digest Mode**: Bundle alerts into summaries

### 3.3 Testing Your Alerts

#### Alert Testing
1. **Test Configuration**
   - Go to Alerts → Your Alert → Test
   - Send test notification
   - Verify delivery channels

2. **Sample Data**
   - Use platform sample data to test
   - Create mock legislative events
   - Verify alert triggering
